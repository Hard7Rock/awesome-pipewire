## GUI
- [Cable](https://github.com/magillos/Cable) — PyQt application to dynamically modify PipeWire and WirePlumber settings at runtime.
- [coppwr](https://github.com/dimtpap/coppwr) — Low level control GUI for the PipeWire multimedia server.
- [Helvum](https://gitlab.freedesktop.org/ryuukyu/helvum) — GTK-based patchbay for pipewire, inspired by the JACK tool catia.
- [hyprpwcenter](https://github.com/hyprwm/hyprpwcenter) — A GUI PipeWire control center.
- [PipeWireController](https://github.com/knightinfected/PipeWireController) — GTK4/libadwaita audio control center for PipeWire.
- [pw-viz](https://github.com/Ax9D/pw-viz) — PipeWire graph editor written in Rust.
- [pwvucontrol](https://github.com/saivert/pwvucontrol) — PipeWire Volume Control.
- [qpwgraph](https://github.com/rncbc/qpwgraph) — PipeWire Graph Qt GUI Interface.
- [wiremix](https://github.com/tsowell/wiremix) — Simple TUI audio mixer for PipeWire.

## Effects
- [EasyEffects](https://github.com/wwmm/easyeffects) — Limiter, compressor, convolver, equalizer and auto volume and many other plugins for PipeWire applications.
- [JamesDSP for Linux](https://github.com/Audio4Linux/JDSP4Linux#readme)

## Visualizers
- [catnip](https://github.com/noriah/catnip) — Terminal audio visualizer for linux/unix/macOS.
- [cava](https://github.com/karlstav/cava) — Cross-platform audio visualizer.

## Audio Routing & Sharing
- [audio-share](https://github.com/mkckr0/audio-share) — Share Windows/Linux computer's audio to an Android phone over the network.
- [obs-pipewire-audio-capture](https://github.com/dimtpap/obs-pipewire-audio-capture) — Audio device and application capture for OBS Studio using PipeWire.
- [pulsemeeter](https://github.com/theRealCarneiro/pulsemeeter) — A PulseAudio and PipeWire audio mixer inspired by Voicemeeter.
- [PWAR](https://github.com/ripxorip/PWAR) — PipeWire ASIO Relay — a zero-drift, real-time audio bridge.

## Guides & Resources
- [PipeWire-Guide](https://github.com/mikeroyal/PipeWire-Guide) — Learn about how PipeWire gives your Linux system a professional Audio/Video processing workflow.
